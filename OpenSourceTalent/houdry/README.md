## 课程说明

本项目完成了 OpenSourceTalent Task 1，基于 Kotlin Multiplatform 与 Kuikly Compose DSL 实现可复用的跨平台 KuiklyCalendar 月份网格日历组件。项目包含 42 格日期网格、跨年月份切换、单日期选择、日期回调、纯 Kotlin Gregorian 算法、单元测试、Demo、API 文档和开发验收记录，代码和完整说明均在公开仓库中。
