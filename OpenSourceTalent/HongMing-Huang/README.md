## 课程说明

本项目基于 Kuikly 实现了 AI 股票应用「知牛 ZhiNiu」，完成 Task 1 与 Task 2。Task 1 实现行情列表、个股详情（K 线、分时、财务、资讯）与自选管理，行情为真实数据；Task 2 实现多 Agent AI 问答、流式输出与 Markdown 渲染，并支持用自然语言直接操作 App（加自选、设预警、双股对比）。业务代码一套 commonMain，H5、Android、iOS、鸿蒙多端运行；项目 README 提供运行说明与演示截图。
