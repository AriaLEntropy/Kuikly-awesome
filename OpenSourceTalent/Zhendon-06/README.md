## 课程说明

本项目完成 Task 1 与 Task 2：基于 Kuikly 和 Kotlin Multiplatform 实现跨 Android、iOS、OpenHarmony 的 AI 股票应用。项目包含今日行情列表、股票详情与 K 线/分时图、AI 预测和风险提示；支持 AI 股票问答、Markdown 与结构化行情卡片、卡片点击跳转详情并带回聊天继续追问。仓库 README 和 docs 中提供架构、数据来源、构建运行说明及演示视频。
