## 课程说明

KuiklyStock 是基于 Kuikly 实现的 Android 股票行情与 AI 研究 Demo。它支持行情搜索、筛选和详情查看，也能在 AI 会话中展示 Markdown、股票卡片和走势图；实时服务不可用时会自动切换到内置演示数据，方便离线验收。

DSH App 是 DeepSeek Harness 的 Android、iOS 移动端界面，手机可通过扫码 Relay 或 SSH 连接电脑上的 Host。目前已实现流式 Markdown 会话、图片选择和拍照发送、会话重命名与归档，并完成了消息复制和会话导出、插件状态查看、脱敏日志中心等扩展能力。普通文件附件、LaTeX 渲染、完整的局部文本选择、插件配置摘要和问题反馈入口暂未实现。
