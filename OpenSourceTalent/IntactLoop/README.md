\## 课程说明



本项目完成了「基于 Kuikly 开发 AI 股票行情原型 Demo」课题，基于腾讯 Kuikly 跨端框架（Compose DSL），使用 Kotlin Multiplatform 开发了一套 AI 股票行情应用。核心功能包括：多市场行情列表（沪深/港股/美股）、指数与板块总览、个股详情（多周期 K 线、复权切换、成交量副图）、AI 信号解读与买卖建议、图表联动分析、AI 智能问答、多股对比与 AI 综合分析、自选股管理、选股分类与榜单等。所有 AI 场景均采用「预生成模板 + Mock 数据填充」实现，不依赖真实 LLM API，确保 Demo 演示稳定流畅。
