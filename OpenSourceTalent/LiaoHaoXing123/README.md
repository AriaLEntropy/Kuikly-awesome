## 课程说明

本项目 Kuikly Stock 基于腾讯 Kuikly 与 Kotlin Multiplatform 开发，完成了 Task 1 和 Task 2。

- **Task 1 · AI 股票行情原型 Demo**：实现股票行情列表与个股详情页，展示名称、代码、最新价、涨跌额、涨跌幅及最高价、最低价、成交量等信息，支持搜索、排序、滚动浏览和详情跳转；提供 K 线、分时图及 AI 智能解读，展示趋势判断、支撑压力价位、风险提示，并支持分析依据与 K 线联动。
- **Task 2 · AI 股票问答应用 Demo**：实现 AI 聊天主页面，支持问题输入、消息发送、多轮对话、流式输出与历史会话管理；使用 KuiklyMarkdown 渲染 Markdown，结合股票卡片、图表和行情依据卡片展示结构化回复，并支持从聊天结果跳转至股票或指数详情页，查看行情、走势与分析内容。

项目仓库 README 提供技术架构、运行方式和演示视频入口，使用指南提供各功能的详细操作说明。
