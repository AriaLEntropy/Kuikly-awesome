## 课程说明

本项目完成了 **Task 3**：基于腾讯 **Kuikly / Kotlin Multiplatform** 实现 DeepSeek Harness（DSH）的移动端宿主 App `deepseek-harness-mobile`。一套 Kotlin 代码落地 **Android / iOS / OpenHarmony** 三端，App 通过**扫码连接（Relay）**或 **SSH 隧道**远程接入电脑端 DSH Host，提供多轮对话、会话管理、附件、插件与日志等移动端宿主界面；在此基础上按任务集完成了主题、文本、附件、会话、插件、日志与公式渲染等多项增强：

- **Task 1 主题适配**：浅色 / 深色 / 跟随系统三种模式，切换立即生效、重启保持，深色下代码块与错误色清晰可读；加分项实现独立代码主题与 **按系统日出日落自动切换**。

- **Task 2 文本选择复制导出**：长按局部选择、一键复制完整正文、代码块独立复制、完整可读导出并保留文本/卡片/工具顺序；加分项实现多选批量导出与（WebView+系统打印）PDF 导出。

- **Task 3 图片与文件附件上传**：相册选图 / 拍照发送四类官方格式，上传前预览移除、上传中状态、失败删除与重试，附件按 `attachmentId` 历史恢复，发送前按 `imageLimits` 拦截；加分项实现缩略图+全屏查看、扩展 Host 的 PDF/文本通用文件通道。

- **Task 4 会话删除、重命名与归档**：`session.rename` 重命名、`workspace.archiveSession` 归档、独立归档列表打开历史、归档二次确认与当前会话自动切换；加分项扩展 Host 实现 **归档恢复（unarchive）** 与永久删除。

- **Task 5 插件菜单与状态展示**：展示远程 Host 插件清单、状态点、失败原因与配置摘要，支持名称搜索与状态过滤；加分项实现插件详情、状态刷新，并通过扩展 Host 协议支持安全的启停与重载。

- **Task 6 日志中心与问题反馈**：结构化收集连接 / RPC / 会话事件 / 错误日志，支持等级、类型与时间筛选、详情、脱敏复制与导出、有界本地存储与清空；加分项实现一键反馈包、崩溃捕获与日志跳回会话。

- **附加题 Markdown 与 LaTeX**：标题/列表/引用/表格/链接、行内与代码块、行内 `$...$` 与块级 `$$...$$` 公式、跨分片到达的公式与非法公式安全降级，深色模式适配；加分项支持公式复制为源文本与复杂矩阵/分式/上下标/希腊字母。

聊天、协议、存储与主题逻辑均放在 Kuikly 共享层（`shared/src/commonMain`），三端仅保留平台宿主。
