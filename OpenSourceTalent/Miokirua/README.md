## 课程说明

本项目完成了 Task 1 与 Task 2，基于 Kuikly（Kotlin Multiplatform）实现了一套代码运行在 Android、iOS 与 HarmonyOS 上的 AI 股票行情应用。支持自选股增删改与分组管理、实时行情刷新、分时图与日/周/月 K 线的交互读数和关键位标注，并接入可运行时配置的大模型提供 AI 问答与行情分析。
