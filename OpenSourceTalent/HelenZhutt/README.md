## 课程说明

本项目完成了 Task 1 & 2，基于 Kuikly 实现了跨平台 AI 股票投研助手“知势”，涵盖真实行情、自选股分类、智能搜索、5日/20日走势切换、AI 上下文问答、股票歧义消解及单股/多股结构化对比等功能。项目已完成 Android、iOS 和 HarmonyOS 三个平台的代码适配与工程配置；由于开发者目前身处海外，受 HarmonyOS 模拟器设备镜像及相关服务的区域访问限制，暂时无法完成鸿蒙端的模拟器运行展示，因此演示视频主要展示 Android 和 iOS，完整 HarmonyOS 代码已保留在仓库中供评审查看。
