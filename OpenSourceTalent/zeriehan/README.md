## 课程说明

本项目完成了 Task 1 与 Task 2，基于 Kuikly 实现了一个股票行情 + AI 问答应用。行情部分接腾讯、新浪、东方财富三家真实接口，覆盖大盘指数、板块、个股榜单与 K 线分时；AI 部分接入智谱 GLM 实现流式问答，还支持用自然语言直接操作 App（改主题色、加自选、设预警等）。13 个页面全部写在 Kuikly 共享层，当前落地 Android。
